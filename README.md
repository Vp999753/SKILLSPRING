# scorecalculatorapp

A React hands-on-lab project: a "Student Management Portal" with a function
component, `CalculateScore`, that accepts a student's Name, School, Total
and Goal, and displays the calculated average score.

## Structure
```
scorecalculatorapp/
├── public/
│   └── index.html
├── src/
│   ├── Components/
│   │   └── CalculateScore.js
│   ├── Stylesheets/
│   │   └── mystyle.css
│   ├── App.js
│   └── index.js
└── package.json
```

## Run locally
```bash
npm install
npm start
```
Then open http://localhost:3000
